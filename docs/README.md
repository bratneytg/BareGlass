# Documentación de BareGlass

Documentos separados por tema. Léelos en este orden; cada uno explica el tema, compara alternativas y termina con una recomendación para empezar barato y poder crecer.

| # | Documento | De qué trata |
|---|---|---|
| 01 | [Pagos](01-pagos.md) | Cómo cobrar: procesadores de adultos, cripto, prepago, plataformas que *no* sirven, y cómo conectar cada uno con el código. |
| 02 | [Suscripciones y modalidades](02-suscripciones-y-modalidades.md) | Modelos de precio (freemium, suscripción, pago único, créditos, códigos), planes, pruebas, cancelación y control de abusos. |
| 03 | [Marketing y publicidad](03-marketing-y-publicidad.md) | Posicionamiento discreto, canales gratuitos y de pago, alianzas, plan de 90 días y métricas. |
| 04 | [Base de datos de usuarios](04-base-de-datos-usuarios.md) | Dónde y cómo guardar usuarios y enlaces: alternativas por coste, seguridad y camino de escalado (Well-Architected). |
| 05 | [Verificación de edad](05-verificacion-de-edad.md) | Opciones (estimación facial, documento, app europea), costes y cómo encajarlas en el registro. |
| 06 | [Ingresos y escenarios](06-ingresos-y-escenarios.md) | Fuentes de ingreso, números de ejemplo y la regla para saber si la publicidad de pago sale a cuenta. |
| 07 | [Legal y distribución](07-legal-y-distribucion.md) | Dónde se puede distribuir, protección de datos, contenido de terceros y lista previa al lanzamiento. |

> Los precios y políticas cambian con frecuencia: las cifras son orientativas y llevan la fecha de consulta (noviembre de 2026). No es asesoría legal ni fiscal.
